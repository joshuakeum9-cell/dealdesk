About this project

Why DealDesk exists

Management consulting deliverables follow patterns: the same document types, the same analytical structure, the same executive audience. DealDesk explores how much of that structure can be systematized so consultants spend their time on judgment, not formatting. It is a portfolio project built around the core deliverables of strategy, operations, and M&A consulting.

DealDesk. A portfolio project by Joshua Keum. Demo only. No client data is stored.
